| **Project** | 11 — Wildlife Species Identification and Conflict Alert System |
| **Industry domain** | Wildlife Conservation |
| **Specific need** | A protected area runs a camera-trap network whose images are reviewed weeks after capture. Human–wildlife conflict (predators at livestock sites, megafauna at cropland edges) is therefore known only retrospectively, so both prevention and compensation are late. Automated species identification plus a *risk-gated* alert turns a backlog into a prioritised queue. |
| **Target user** | Field ranger / conflict-mitigation officer operating a camera-trap network, mostly offline, on low-power hardware. |
| **Operating context** | Measured on the chosen corpus: 34.2 % of frames contain no animal; 32.1 % of animal frames are shot between 18:00 and 06:00 (infrared); frames arrive in bursts of median 5, max 10 per visit; 323 camera sites over 2013–2015. |
| **Success criterion** | Set on 2026-10-23 from the **measured baseline**, before the innovation is evaluated, so the target is not fitted to the result. Measured on the official held-out-site test split (19,928 images, 44 camera sites absent from train, seed 13): `majority_class` 0.0201 and `random` 0.0645 macro F1; **baseline (frozen ResNet-50 + logistic head) 0.6245 macro F1 / 0.7623 accuracy**. Acceptance bar: final species model ≥ 0.6245 test macro F1, with the ≥50-image-class variant reported alongside; **alerts per camera-day ≤ 50 % of the per-frame alerting rate at ≥ 0.90 recall of qualifying (tier ≥ 3) species**; detector mAP@0.5 ≥ 0.55 and IoU ≥ 0.50 on the boxed subset; latency and peak VRAM measured, not estimated. |
| **Baseline** | Frozen ImageNet ResNet-50 features + class-balanced logistic regression — no deep training at all, measured 0.6245 test macro F1 / 0.7623 accuracy against the two trivial references above. The proposed model (fine-tuned `fc,layer4`, 8 epochs, AdamW 1e-4, inverse-frequency class weights) scored **0.6043 test / 0.5520 val**: it *lost* 0.0202 macro F1 out-of-distribution while gaining ~0.012 in-distribution, its test curve peaked at epoch 4-5 and then slid while train loss fell 1.53 → 0.26. That negative result is reported as-is, and `notebooks/04` tests the diagnosis (backbone adapted to seen sites) against head variants on one cached feature bank. |
| **Proposed architecture** | ResNet-50 backbone → 13-way species head (`empty` + 12 species, cattle included); YOLO detector and a torchvision Faster R-CNN (ResNet-FPN) on a separate boxed set for mAP/IoU; LSTM over camera-trap event sequences for the alert decision; transformer context classifier, Mask R-CNN instance segmentation and a 64-px VAE scheduled for Phase II. Full tensor-shape trace in the architecture notebook. |
| **Innovation hypothesis** | Temporal-context gating: risk is scored from the camera-day evidence stream (tier-weighted, exponentially recency-decayed, night-biased, `min_visits=2`) instead of firing on every detection frame. Pre-registered operating point `tier_min=3, min_visits=2, half_life=6 h, night_weight=1.5, score_threshold=0.5`; pre-registered target **>= 50 % fewer alerts per camera-day at >= 0.90 qualifying-species recall**. Measured 2026-10-23 on the official test split (633 camera-days, 139 with a qualifying species present, judged against ground-truth labels rather than the rule's own predictions): **alerts 173 -> 74 (-57.2 %) and false alerts 58 -> 11 (-81 %), so the volume half of the target is met; recall 0.453 misses the 0.90 bar** - and that bar was unreachable by any rule on this classifier, because the per-frame rule itself recovers only 0.827 and 24 qualifying camera-days produce no big-cat detection at all. At `min_visits=1` the gate is dominated by per-frame alerting, so its real value is a precision/volume knob (`min_visits=3`: 45 alerts, 1 false, precision 0.978). Revised Phase II target: a recall floor expressed **relative** to the per-frame rule at equal alert volume, plus calibration or a per-species margin test for the residual multi-burst confident confusions. Budget-matched top-K comparison in `notebooks/04`. |
| **Data** | iWildCam v2.0 camera-trap corpus, Kaggle mirror `thanhquang71/iwildcam-v2-0-2020-wilds-dataset` (12.0 GB zip, 203,029 labelled images, 182 species present, 217,640 image files), downloaded 2026-10-23 in ~55 min and extracted locally. Detection boxes come from `ankanghosh651/object-detection-wildlife-dataset-yolo-format` (471 MB), since the species corpus carries **no** bounding boxes. Splits = the benchmark's own `train`/`val`/`test` (199/32/44 camera sites, disjoint on site and date), cut to 12 species + `empty` and capped **by whole sequence** by `src/vision/make_splits.py`; a recarved variant (held-out sites and camera-days) is kept as a robustness check. All leakage overlaps measured at 0. |
| **Compute and time** | RTX 3060 Laptop 6 GB VRAM, 16 GB RAM. Measured on the full split: frozen-feature pass over 66,222 images 484 s; fine-tune epoch (36,060 train + 30,162 eval, batch 64) 259-327 s, 8 epochs 2,480 s. A Kaggle T4 x2 replication was attempted and withdrawn (see `docs/SOURCE_LOG.md` row 11), so every number here rests on the local run alone. Phase I is due within 14 days of 2026-10-23; day-by-day schedule in `PLAN.md` §7. |
| **Risks** | Extreme class imbalance (110 of 182 categories have < 100 images) caps rare-species recall; empty-frame dominance (34.2 %) makes accuracy meaningless as a headline; one class (`tayassu pecari`) has 2 test images and scores F1 0.000, which drags all-13 macro F1 by ~0.077, so both variants are reported; no ground-truth conflict labels exist anywhere in the corpus, so risk is a *designed* rule evaluated by counted false/missed alerts and never a validated predictor; the iWildCam licence is now traced — CDLA-Permissive-1.0 for the WILDS release over CC BY 4.0 Snapshot Safari imagery, so attribution is required and no non-commercial clause applies, though per-image provenance is unverified (evidence in `docs/LICENCE_EVIDENCE.md`); the compendium asks for C/C++/Java while the marking sheet sets no language (sign-off pending). |

Explicit non-intended use: the system must not be used to locate or approach endangered animals, and an alert is triage for a human decision, never an authority to act. Handling of incidental people in frames is stated in the responsible-use section. |
